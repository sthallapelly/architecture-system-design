# Architecture Review Checklist

Use this checklist when reviewing a system.

## Requirements

- [ ] Functional requirements identified
- [ ] Non-functional requirements identified
- [ ] Constraints identified
- [ ] Assumptions documented

## Scale

- [ ] Current scale
- [ ] Peak scale
- [ ] Growth
- [ ] Capacity model
- [ ] Bottlenecks

## Data

- [ ] Data model
- [ ] Ownership
- [ ] Consistency
- [ ] Transactions
- [ ] Retention
- [ ] Backup

## Communication

- [ ] Synchronous vs asynchronous
- [ ] Timeouts
- [ ] Retries
- [ ] Idempotency
- [ ] Ordering
- [ ] Backpressure

## Resilience

- [ ] Dependency failures
- [ ] Partial failures
- [ ] Regional failure
- [ ] Graceful degradation
- [ ] Recovery

## Security

- [ ] Authentication
- [ ] Authorization
- [ ] Encryption
- [ ] Secrets
- [ ] Network boundaries
- [ ] Audit

## Operations

- [ ] Logging
- [ ] Metrics
- [ ] Tracing
- [ ] Alerts
- [ ] SLOs
- [ ] Runbooks

## Evolution

- [ ] Versioning
- [ ] Migration strategy
- [ ] Backward compatibility
- [ ] Technology lifecycle

## Trade-offs

- [ ] Alternatives considered
- [ ] Major decisions documented
- [ ] Consequences understood
