# Architecture Glossary

A growing reference for architecture terminology.

| Term | Short definition |
|---|---|
| ACID | Properties associated with reliable database transactions |
| Backpressure | Mechanism for preventing producers from overwhelming consumers |
| CAP | Trade-off involving consistency, availability, and partition tolerance |
| CQRS | Separating command and query models/paths |
| DLQ | Dead-letter queue for messages that cannot be successfully processed |
| Idempotency | Repeating an operation produces the same intended result |
| RPO | Maximum acceptable data loss measured in time |
| RTO | Target time to restore service |
| Saga | Pattern for coordinating distributed business transactions |
| SLO | Target level of service reliability |
| Outbox | Pattern for reliably coupling database changes with outbound events |
