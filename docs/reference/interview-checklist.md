# System Design Interview Checklist

## Before designing

Ask:

- Who are the users?
- What are the core use cases?
- What scale?
- What latency?
- What availability?
- What consistency?
- What data?
- What constraints?

## While designing

Explain:

- assumptions
- architecture
- data flow
- state ownership
- scaling
- failure modes
- trade-offs

## Before finishing

Check:

- bottlenecks
- retries
- idempotency
- observability
- security
- DR
- cost
- evolution

## Key principle

Do not start with products.

Start with requirements and constraints, then derive the architecture.
